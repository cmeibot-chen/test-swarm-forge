Build and validate a minimal Hello World web app from the SwarmForge
TypeScript + Next.js + PostgreSQL starter.

The app must use TypeScript, Next.js App Router, Tailwind CSS, PostgreSQL,
npm, and Docker Compose. Opening the root page must show Hello World, the
PostgreSQL health path must work in Compose, and the project must pass the
configured TypeScript quality, acceptance, UI, and container checks.
